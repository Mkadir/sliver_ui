# Konsol RPC ni yopadi, oqimni emas

**Bu fork Linear uslubidagi qorong‘u web konsolda session, listener, generate, loot va SOCKS RPC larining katta qismini, plus ushbu daraxtga xos auth, `install.sh`, HTTP C2 sahifasi va host-compile Loaders wrap EXE ni allaqachon beradi; lekin u operator ish oqimi emas, RPC katalogidir.** 2026-11-16 jonli laboratoriya `http://127.0.0.1:8080` da `sliver-ui` Sliver **1.7.9** (`commit 6cf3ad78…`) ga ulangan, **0 session, 0 beacon, 3 job, 1 builder, 0 SOCKS** — ya’ni operatorning eng keng tarqalgan holati: listenerlar yoniq, callback yo‘q ([current_product_inventory](../research_notes/Sliver%20UI%20imkoniyatlar%20tahlili/current_product_inventory.md)). Ko‘rinish to‘ldirilganda professional; bo‘sh holatda 21 ta sidebar qatori, Settings ni bosib turgan Sign out va to‘rtta “No data to chart” kartochkasi hukmron. Eng katta funksional teshik **beacon tasking**: generate `is_beacon` yozmaydi, implant RPC lar `SessionID`-only, operator avval interactive session ochishi shart. **Armory yo‘q**, Events stream **replay qilmaydi**, `GET /api/builders` aslida `ImplantBuilds()` ni `"builders"` kaliti ostida qaytaradi. Raqobatchilar — rasmiy [sliverarmory/sliver-gui](https://github.com/sliverarmory/sliver-gui), [Siren](https://github.com/Gubarz/siren), [Mr-In4inci3le/sliver-gui](https://github.com/Mr-In4inci3le/sliver-gui), [Mythic 4.0](https://docs.mythic-c2.net/), Cobalt Strike va Havoc — graf, command palette, attributed tasking va event viewer da oldinda.
