## What routes, nav groups, pages, and session/beacon tabs exist, and what does each actually do?

### Takeaway
This fork ships a 21-item grouped sidebar plus two nested session/beacon detail routes and a full-page terminal. Almost every Sliver operator surface that has a Go handler also has a React page or a session tab; the information architecture is a flat “Viper-style” dump of those surfaces, not a task-oriented console. Beacons are a list + task history, not a 13-tab workspace.

## What HTTP/WS APIs does the Go backend expose, and which are wired in the React UI vs dead?

### Takeaway
The Go mux is a 141-entry contract (`140` HTTP `/api/*` + `GET /ws/sessions/{id}/terminal`). The React `api.ts` client covers essentially every HTTP path. Two client methods and one GET-by-UUID are unused by pages. Several backend behaviors are wired but wrong or coarse (stage-listener list, listeners badge = all jobs). Auth is a cookie gate in front of `/api` and `/ws`.

### Cited Findings
- Single source of truth: `Server.apiRoutes()` in [`backend/internal/api/server.go`](file:///home/cup/Documents/personal/sliv/backend/internal/api/server.go). `RoutePatterns()` plus the WS endpoint is snapshotted as 141 entries in [`frontend/src/lib/__fixtures__/routes.json`](file:///home/cup/Documents/personal/sliv/frontend/src/lib/__fixtures__/routes.json) (70 POST / 52 GET / 18 DELETE / 1 PUT). Frontend contract test asserts **every `api.ts` call exists on the backend**, not the reverse. — [`frontend/src/lib/__tests__/routes.test.ts`](file:///home/cup/Documents/personal/sliv/frontend/src/lib/__tests__/routes.test.ts)
- Mux also registers `/ws/sessions/{id}/terminal`, `/api/` and `/ws/` 404 JSON, and `/` static SPA. Stack: CORS `*` + logging + `AuthGate` middleware. CORS allow-methods are `GET, POST, DELETE, OPTIONS` — **PUT is omitted** (websites update uses PUT; same-origin so it still works). — [`server.go`](file:///home/cup/Documents/personal/sliv/backend/internal/api/server.go) (lines 250–333)
- Auth: enabled iff both env vars set. Public: `/api/auth/login`, `/api/auth/me`, and any non-`/api` `/ws` path (static). Cookie `sliverui_session`, HttpOnly, SameSite=Lax, MaxAge 24h, **no Secure flag**, sessions **in-process map** (lost on restart). Constant-time compare. Live: unauthenticated `GET /api/sessions` → **401**; `POST /api/auth/login` → `{"success":true,"user":"admin"}`; `GET /api/auth/me` → authenticated admin. — [`backend/internal/api/auth.go`](file:///home/cup/Documents/personal/sliv/backend/internal/api/auth.go); live `http://127.0.0.1:8080/api/auth/me`
- Frontend `fetch` uses `credentials: 'include'` and JSON `Content-Type`. WS URL is `ws(s)://host/ws/sessions/{id}/terminal`. — [`frontend/src/lib/api.ts`](file:///home/cup/Documents/personal/sliv/frontend/src/lib/api.ts) (lines 48–58, 695–698)
